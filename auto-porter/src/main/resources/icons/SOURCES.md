# GUI quick-link icons

PNG files are rendered at 48px width from the accompanying SVG sources and displayed at 16px width in Swing. No network access is needed at runtime.

- Discord: official colored symbol from https://discord.com/branding — https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d80db9971f10a9757c99_Symbol.svg
- GitHub: official favicon mark from https://github.githubassets.com/favicons/favicon.svg — brand guidance: https://brand.github.com/foundations/logo
- Contribute, Report Bug, Suggest Feature: `git-pull-request`, `bug`, and `lightbulb` from https://github.com/lucide-icons/lucide/tree/main/icons, under the accompanying `LICENSE-lucide`.

Discord and GitHub marks belong to their respective owners and identify links to those services.
