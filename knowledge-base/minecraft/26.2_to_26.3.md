## Version: 26.2 → 26.3

### Verified target versions

- Minecraft: `26.3`
- Java: `25`
- Fabric Loader: `0.19.5`
- Fabric API: `0.163.0+26.3`
- Fabric Loom: `1.17.21` (stable build in the official 1.17 line)
- Fabric Gradle wrapper: `9.6.0`
- NeoForge: `26.3.0.88`
- Data Pack: `121.0`
- Resource Pack: `97.1`

### Deterministic automatic migrations

- Updates Fabric and NeoForge dependency properties, including modern `neo_version` and `minecraft_version_range` keys.
- Moves exact Renderpearl classes and package prefixes from Blaze3D where the official primer defines a one-to-one destination.
- Applies exact networking, registry, command, structure-manager, enum, spelling, and nested-class renames.
- Moves `worldgen/configured_feature` to `worldgen/feature` and `worldgen/configured_carver` to `worldgen/carver`.
- Flattens the old top-level `config` object only when doing so cannot overwrite another key.
- Renames `minecraft:basalt_columns` to `minecraft:stepped_column_cluster` and its `reach` key to `column_reach` in matching objects.
- Updates the final data/resource pack formats.
- Renames the verified block and structure tag files and exact identifier references.
- Replaces shader `#moj_import` directives with `#include`.
- Renames the exact `rendertype_clouds` and `rendertype_world_border` core shader files.

### Manual review detections

Auto-Porter reports specific file/symbol warnings rather than guessing for:

- GLFW/SDL input codes and text-input focus handling.
- Render passes, Renderpearl semantic changes, OIT, shader layouts, item quads, and feature phases.
- Reloadable registry, advancement, loot-table, predicate, recipe, and data-generation rewrites.
- Configured feature/carver Java implementations and surface-to-material rule changes.
- Integer/float context provider selection.
- Brewing, fuel, compostable, and block-transformer component migrations.
- Fabric API removals and fluid-name changes.
- NeoForge config type renames, removed compatibility APIs, rendering events, and other signature changes.
- Biome spawn data moved to environment attributes.
- Removed atlases, post effects, models, and any non-one-to-one resource changes.
- Mixins, whose exact targets must be checked against the final 26.3 classes.
